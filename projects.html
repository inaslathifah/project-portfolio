Proyek

Dua proyek tim yang saya kerjakan dari sisi UI/UX hingga integrasi desain ke frontend, plus satu video demo singkat.

Parkify

Berkolaborasi dengan tim Front-End dan Back-End untuk mengembangkan Parkify, aplikasi yang menjadi satu-satunya platform yang bekerja sama dengan penyedia layanan parkir di berbagai lokasi seperti gedung, kawasan komersial, dan pusat perbelanjaan. Saya berkontribusi dalam merancang UI menggunakan Figma, membuat logo Parkify, dan melakukan UI slicing.

  • React.ts
  • Tailwind CSS
  • Vite
  • Shadcn/UI

PetPal

Tim kami, terdiri dari anggota Front-End dan Back-End, berkolaborasi mengembangkan PetPal, platform khusus untuk kebutuhan hewan peliharaan. Aplikasi ini menghadirkan berbagai fitur yang memudahkan pemilik hewan peliharaan membeli kebutuhan hewan dan berkonsultasi dengan dokter hewan, baik secara online maupun kunjungan langsung. Sebagai project leader, saya bertanggung jawab merancang UI di Figma, membuat logo PetPal, melakukan UI slicing, dan mengintegrasikan desain ke frontend.

  • React.ts
  • Tailwind CSS
  • Vite
  • Shadcn/UI
  • Leaflet
  • Figma
